Калькулятор матриц

Цель: освоение полного цикла разработки ПО (написание кода, тестирование, документирование, контейнеризация и CI/CD).

Проект реализует библиотеку для работы с матрицами:
*   Базовые операции
    *   Создание и освобождение памяти (`create_matrix`, `free_matrix`).
    *   Сложение матриц (`matrix_add`).
    *   Умножение матриц (`matrix_multiply`).
    *   Создание из одномерного массива (`matrix_from_array`).
    *   Вывод в консоль (`print_matrix`).
    *   Вычисление определителя матрицы 2×2 (`matrix_determinant_2x2`).
